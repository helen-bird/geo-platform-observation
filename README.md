# GEO Learning Log

An ongoing record of experiments, resource reviews, and lessons from learning Generative Engine Optimization (GEO). Each stage preserves its questions, methods, evidence, and limitations for review and future revision.

## Stages

| Stage | Learning focus | Materials |
| --- | --- | --- |
| Stage 1 | Repeated queries to ChatGPT Search and Grok to explore the differences between Citation, Mention, and Recommendation | [Learning notes and data guide](stages/01-platform-observation.md) · [Visual report](https://helen-bird.github.io/geo-platform-observation/) |
| Stage 2 | Test whether an original public experiment post can be accessed by URL, found by an exact excerpt, or discovered through an unbranded question | [Learning notes and data guide](stages/02-post-discovery.md) · [Visual report](https://helen-bird.github.io/geo-platform-observation/stages/02-post-discovery/) |
| Stage 3 | Explore how repeated prompts, wording variants, and measurement-versus-validation intent change advice, sources and tool recommendations in Grok and OpenAI API web search | [Learning notes and data guide](stages/03-question-sensitivity.md) · [Visual report](https://helen-bird.github.io/geo-platform-observation/stages/03-question-sensitivity/) |

New stages will be added as learning and experiments are completed. Each stage documents its findings, data, reproduction commands, and publication scope. Stage 1's report remains at the main website address; later stages have their own reports and data directories. File history preserves subsequent corrections.

> Stage 3's OpenAI arm uses the **Responses API with web search**, not the ChatGPT consumer website or app. Its results cannot represent ChatGPT web/app performance. Each stage records its actual collection conditions and limits rather than treating different interfaces as equivalent.
