Use the evidence

  • Read by user intent. Results from different tasks should not be pooled into a universal recommendation score.
  • Keep outcomes distinct. Page citation, content-brand recommendation, personal-name mention and personal recommendation are different observations.
  • Check the collection interface. Labs #03 and #04 use OpenAI Responses API + web search. They do not represent consumer ChatGPT Search performance.

Each report links an expanded methods/evidence appendix and downloadable public data. Lab #05 publishes reviewed aggregates rather than raw engine/account responses.
