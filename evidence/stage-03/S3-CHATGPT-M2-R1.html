Original prompt

As a bootstrapped SaaS builder, what's a free, repeatable workflow for checking whether my product appears in ChatGPT and Grok recommendations?

The agreed prompt is reproduced exactly. Any recorded difference in the actual submitted text or search UI is retained in the raw record and full appendix.

Original answer

## A free weekly “AI recommendation audit”

Use the free versions of ChatGPT and Grok, a spreadsheet, and roughly 30 minutes per run. ChatGPT web search is available on the Free plan, while Grok is also free to start and can search both the web and public X posts. ([help.openai.com](https://help.openai.com/en/articles/9237897-searching-the-web-with-chatgpt))

### 1. Build a 10-prompt test set

Choose prompts representing how buyers actually shop—**without mentioning your product**.

| Intent | Prompt template |
|---|---|
| Category | “What are the best `[category]` tools for `[ICP]`?” |
| Problem | “I need to `[job]` without `[pain]`. What tools should I consider?” |
| Constraints | “Recommend five `[category]` tools for `[ICP]` under `$X/month`.” |
| Alternative | “What are the best alternatives to `[market leader]` for `[use case]`?” |
| Shortlist | “Which tools should a `[role]` shortlist for `[outcome]`?” |
| Comparison | “Compare the leading tools for `[job]`, including price, strengths and weaknesses.” |

Create variants for your two or three most important personas, use cases, or geographies. Keep the same prompts each week.

### 2. Run two versions of every prompt

**A. Default recommendation**

> What are the five best `[category]` tools for `[ICP/use case]`? Rank them and briefly explain each choice.

This tests what a normal user may experience.

**B. Web-grounded recommendation**

> Search the web for current information. Recommend five `[category]` tools for `[ICP/use case]`. Include pricing, explain the ranking, and cite the sources used.

This reveals whether your site—or third-party pages mentioning you—enters the retrieval layer. ChatGPT search responses can include clickable citations, although OpenAI warns that citations can still be incomplete or incorrect. ([help.openai.com](https://help.openai.com/en/articles/9237897-chatgpt-search))

### 3. Keep every run clean

For **ChatGPT**:

- Start a new **Temporary Chat**
- Choose **Unpersonalized**
- Don’t use a conversation in which you previously discussed your company
- Don’t mention your brand until after the unaided test

OpenAI states that unpersonalized Temporary Chats do not use memories, custom instructions, or plugins for personalization. ([help.openai.com](https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt))

For **Grok**:

- Start a fresh conversation
- Disable Grok personalization where available
- Ideally use a dedicated testing account with no company-related posting or chat history

On X, Grok personalization can incorporate profile, posts, engagement, interests and previous Grok interactions, so testing through your founder account can skew results. ([help.x.com](https://help.x.com/en/using-x/about-grok))

Incognito mode alone is insufficient if you sign into a personalized account.

### 4. Repeat each test three times

Model answers vary. Run each prompt:

- Three times on ChatGPT
- Three times on Grok
- In separate fresh conversations
- On the same day, if possible

If free-tier limits make that excessive, rotate the set:

- Week 1: five prompts
- Week 2: the other five
- Repeat monthly

### 5. Record results in a spreadsheet

Use these columns:

```text
Date
Platform
Prompt ID
Prompt
Default or web-grounded
Product mentioned? Y/N
Rank
Description accurate? Y/N
Positive / neutral / negative
Our website cited? Y/N
Third-party page citing us
Competitors mentioned
Competitor source domains
Notes
Screenshot/chat link
```

Track four metrics separately:

1. **Mention rate:** percentage of runs mentioning you  
2. **Top-three rate:** percentage ranking you first through third  
3. **Citation rate:** percentage citing your website or a page featuring you  
4. **Accuracy rate:** percentage describing your positioning, pricing and features correctly  

Example:

```text
Mention rate = mentions / total runs
Top-3 rate = top-3 appearances / total runs
Owned citation rate = runs citing your domain / total runs
```

Don’t combine these into one score initially. “Frequently mentioned but inaccurately described” is a different problem from “rarely mentioned but ranked highly when found.”

### 6. Add a separate branded diagnostic

After the blind tests, open another clean conversation and ask:

> What is `[Product]`, who is it best for, what are its main alternatives, and why might someone choose or avoid it? Search the web and cite every factual claim.

This does **not** measure recommendation visibility. It diagnoses:

- Whether the model can identify your company
- Category confusion
- Outdated pricing
- Incorrect features
- Which pages it treats as authoritative
- Which competitors it associates with you

### 7. Turn the findings into a content queue

When you’re absent, inspect what the models cited instead. Look for repeat patterns:

- “Best tools” articles
- Software directories
- Reddit or community discussions
- Competitor comparison pages
- Integration directories
- Documentation
- Pricing pages
- Public X discussions, especially for Grok

Then make one measurable improvement per week:

- Clarify your homepage category and ideal customer
- Publish a detailed pricing page
- Create a page for each important use case
- Publish honest “X alternative” and “X vs. Y” pages
- Add comparison tables with concrete facts
- Improve documentation and integration pages
- Correct inaccurate third-party listings
- Earn inclusion in the specific independent pages repeatedly cited
- Encourage genuine customers to publish detailed reviews and use-case discussions

Avoid manufacturing reviews, fake community posts, or mass-produced “best tools” pages. The audit should tell you where real, verifiable product information is missing.

## Recommended cadence

- **Weekly:** Run five highest-value prompts
- **Monthly:** Run the complete matrix three times per platform
- **After major launches:** Run the branded accuracy diagnostic
- **Quarterly:** Replace low-value prompts using language from sales calls, support tickets and search data

The key is to treat this as a **longitudinal visibility test**, not a definitive ranking checker. Results vary by model, search mode, personalization, location and time; your trend over repeated controlled runs is more meaningful than any single answer.
