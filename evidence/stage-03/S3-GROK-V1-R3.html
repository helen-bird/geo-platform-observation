Original prompt

I'm a solo SaaS founder with no GEO budget. How can I tell whether an AI visibility score for ChatGPT and Grok is trustworthy?

Original answer

Treat any single AI visibility score for ChatGPT or Grok as a directional estimate, not a trustworthy absolute number. These scores are estimates built by prompting models (often via API or consumer interfaces), and the underlying systems are highly non-deterministic. Engines frequently disagree with each other, and the same prompt on the same engine often produces different brand lists and sources.⁠Markets.businessinsider

Why most scores are only partially trustworthy

Independent studies and benchmarks show significant variance:

Same-engine shortlist overlap on repeated runs is often only around 40–55% (or lower for exact matches). Cross-engine overlap is typically much lower (e.g., ~17% in one multi-engine test).⁠Markets.businessinsider
A single run of a prompt captures only a fraction of the brands that appear across multiple runs. “Ghost” brands that appear once and disappear are common.
No vendor has access to real OpenAI or xAI user conversation logs. Scores are synthetic samples of what the models can say under controlled conditions, not what actual users see (personalization, location, history, and model updates add more noise).

The biggest red flag is a single blended “AI Visibility Score” (e.g., 73/100) with no per-engine breakdown, no prompt list, and no disclosure of how many times each prompt was run.⁠Amicited

How to evaluate a score’s trustworthiness

Ask these questions (or check the methodology page):

Per-engine breakdowns — Separate results for ChatGPT and Grok (and ideally others). A blended number hides large differences.
Sampling depth — How many times is each prompt run? One run is nearly useless. Look for at least 3–5 (better tools go higher and report ranges or confidence intervals).
Prompt transparency — Exact prompts used? Are they non-branded buyer-intent questions (“best tool for X use case,” “Y alternatives,” “how to solve Z”) rather than “what is [your brand]?”
Raw data access — Can you see the actual answers, cited sources, competitors mentioned, position, and sentiment/accuracy notes?
Methodology details — Models/versions, whether web search was enabled, timing between runs, and any caveats about variance.
No overclaiming — Tools that call the number “accurate” or claim it reflects real user visibility without heavy caveats are less credible.

Good signals include published methodology, multi-run sampling, engine-level views, and the ability to inspect answers. Opaque proprietary scores are low-trust.

Zero-budget way to check it yourself (recommended)

You can build a more reliable baseline than most vendor scores by doing controlled manual testing:

Build 10–15 real buyer prompts for your SaaS category. Focus on commercial-intent, non-branded queries your customers actually type.
Run them on ChatGPT and Grok:
ChatGPT: Use a private/incognito window, turn off Memory/personalization if possible, and enable web search.
Grok: Use a fresh session on x.com or the app.
Run each prompt 3 times (or 5 if you can), spaced out. Log every result.
Track in a simple Google Sheet: Prompt | Engine | Run # | Mentioned? | Position | Competitors | Sources cited | Notes on accuracy/sentiment.
Calculate simple rates per engine (e.g., mention rate = % of runs where you appear). Retest monthly to see trends.
Cross-check free signals:
Google Search Console Generative AI / AI Overviews report.
GA4 AI Assistant channel (referrals from ChatGPT, Grok, etc.).
Free one-off checkers from Ahrefs, Semrush (limited free checks), or HubSpot’s AI Search Grader for a quick snapshot.

This takes a few hours the first time and gives you data you control. Variance will still exist, but averaging multiple runs makes the signal usable.

Practical takeaway for a solo founder

Don’t optimize for a vendor score. Use manual multi-run checks (or free snapshots) as your source of truth for ChatGPT and Grok. Focus effort on things that consistently correlate with mentions across studies: third-party mentions (YouTube, reviews, industry sites, LinkedIn), entity consistency (schema, consistent naming, Crunchbase/LinkedIn/Wikidata signals), clear quotable content with stats and citations, and allowing relevant AI crawlers while managing robots.txt carefully.

A trustworthy score is transparent about its limitations, shows per-engine multi-run data, and lets you verify the underlying answers. Anything else is marketing. Start with your own spreadsheet baseline—it will be more useful than most paid dashboards at your stage.
