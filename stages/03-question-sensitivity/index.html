GEO advice across question variants

A small repeated-prompt study of GEO measurement and score-validation advice for independent SaaS builders.

OpenAI API + web search, not consumer ChatGPT Search. These results do not represent ChatGPT web app performance.
  • Repeated questions still produced different details. Grok’s strict named-recommendation sets varied across the three repeats. OpenAI API M1 also changed its proposed scoring rubric from 0–3 in the first two runs to −1/0–4 in the third. Generated rubrics are advice, not validated measurement standards.
  • Matched comparisons describe lower cross-wording overlap in the Grok sample. Using the same answer-pair Jaccard metric, M averaged 35.5% within wording versus 26.0% across wording; V averaged 45.5% versus 27.0%. Six within and nine cross pairs reuse six answers per intent. These descriptive post-hoc comparisons do not identify a causal wording effect.
  • The entity definition changes the headline overlap. OpenAI API M1/M2 pooled overlap is 0/7 under strict names and 1/6 when Google Analytics and explicitly named GA4 are grouped at the declared family level. This is a sensitivity result, not a correction to the original strict labels; coarse categories can increase overlap mechanically.

What this cannot show

  • No platform winner or GEO effectiveness result. Grok Expert · consumer interface and OpenAI API + web search differ in interface, retrieval, model identity and collection time; all API answers were collected after Grok.
  • No pure wording effect. The variants also change budget and action cues. Three responses per exact prompt cannot establish stable recommendation probabilities.
  • Review remains bounded. Human-review status: awaiting independent human review. Coding is assistant semantic review; assistant audits are not independent human double-coding. Source-audit status: 6 selected sources reviewed; 5 exact pages accessible; 1 exact page unavailable. Only explicitly checked claims have external review evidence.
  • Citation coverage differs. Three early Grok captures lack strict complete URL mapping. Source composition is supplementary and does not establish intrinsic platform preferences.

Implications for a GEO prompt bank

  • Keep measurement and score-validation intents separate, and preserve each exact wording version.
  • Repeat a fixed prompt before interpreting differences across variants; retain the answer, date, model/interface and search evidence.
  • Report strict entities alongside any family mapping. Keep Citation, Mention and Recommendation separate, and name the denominator.
  • Treat generated scores, weights and sampling rules as advice to evaluate, not validated measurement instruments.
