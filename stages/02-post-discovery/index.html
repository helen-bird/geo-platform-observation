Can AI find a new experiment post?

A small observation of direct access, exact-excerpt discovery and natural discovery across ChatGPT Search and Grok.

  • A supplied URL enabled access in the selected Grok run. Grok retrieved body-specific facts that met the post-access criterion. ChatGPT explicitly said it could not access the actual post. This is one answer per environment, not a platform-wide ranking.
  • The exact excerpt did not produce a qualifying target-post result in either selected B answer. The excerpt matches the captured post character for character. Grok's actual web/X activity was recorded; ChatGPT B's executed search queries were not independently captured.
  • Neither selected natural-query answer found and cited the target X post. Finding other researchers, the author or a GitHub report is a separate outcome. ChatGPT C is a later manual replacement with qualified control evidence.

Collection summary: 6 planned cells · 10 actual submissions · 6 complete selected answers. Four earlier ChatGPT C attempts had technical or body-capture problems before a complete manual replacement was obtained. Those records remain in the dataset.

Completeness describes the selected captures; it does not mean collection was failure-free. No stable retrieval success rate or GEO optimization effect is estimated.

Methods in brief

  1. Use fresh visible temporary/private conversations and the unchanged A/B/C questions. The target is the original GEO Lab #01 X post.
  2. Evaluate post-body access, exact discovery and unprompted discovery separately. Merely returning the supplied URL, repeating the quote or reading linked GitHub content is insufficient for post access.
  3. Preserve all ten actual submissions and select six complete records. Recovery of an existing message is not another query. All four earlier C technical/partial captures remain visible.

Exact text: the registered B quote is an 86-character continuous fragment from the latter part of a sentence, including the U+2014 em dash and final period. Both B prompts preserve it unchanged. No transcription difference was observed. An exact prompt does not establish the literal query a platform sent to a search service.

What this cannot show

  • Six selected answers cannot estimate reliable discovery rates, prove indexing failure or show that the post is absent from X.
  • The post was new, and indexing delay is a possible explanation rather than an established cause. A later native-X result would concern another search surface and time.
  • Visible account controls do not audit backend isolation. ChatGPT's manual C replacement has different control evidence; Grok's backend version is not disclosed.
  • This is a small exploratory observation, not evidence that a GEO tactic worked or that either platform is inherently better.
