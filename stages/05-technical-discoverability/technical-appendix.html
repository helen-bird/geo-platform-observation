GEO Lab #05: Methods and Source Notes

Methods and source notes for the fifth learning record. This is a summary of technical observations, not an archive of new AI answers.

Publication boundary. The public JSON reproduces the visible aggregate tables. It is not a raw Search Console or Bing export. Private raw responses, screenshots, account/verification identifiers, secrets and private workflow links are not published.

Initial design and units

  • Google: 10 important editorial/navigation/appendix URLs, checked with the official indexed-version URL Inspection API.
  • Bing: 70 canonical content URLs, plus read-only site and Sitemap queries. A successful batch therefore has 72 API reads, not 72 indexed pages.
  • OpenAI eligibility: 70 public URLs checked for observable configuration/access conditions and fetched using a declared crawler user agent.
  • IndexNow: 70 deployed content fingerprints in the initial ledger. Only a verified real content addition, material update or deletion is eligible for a notification.

Lab #05 is not the postponed AI-search experiment. No ChatGPT/Grok prompt, recommendation rate, brand mention uplift or citation effect was measured here. The earlier AI-answer evidence library remains at 60 selected answers across Labs #01–#04.

Rules that protect the record

  • Retain original fields and immutable snapshots. Keep derived summaries separate from source observations.
  • Query success and HTTP status never override a missing indexed-version verdict.
  • Keep each planned URL, including failures and zero-attempt skipped positions.
  • Use a fixed property and approved read operations. Google readonly authorization and Bing's account-wide API key are different permission models; the program limits Bing calls to the approved site.
  • Keep credentials in protected storage and private encrypted workflow Secrets, never public content or state.
  • Preserve uncertain delivery state. A received IndexNow request or a confirmed notification is not a crawl/index confirmation.
  • Compare source times and execution environments. One local or manually dispatched success cannot prove every recurring scheduled run will pass.

Official references

  • Google URL Inspection API

    Queries the indexed version; it is not a live test or an indexing request.

  • Google Sitemap fields

    Submission, processing and download observations are separate fields.

  • Bing GetUrlInfo

    The returned URL fields do not supply an unambiguous membership verdict.

  • Bing API fault codes

    ThrottleHost is code 5; the observed response used HTTP 400.

  • Bing URL Inspection

    Index details and a live URL check answer different questions.

  • IndexNow protocol

    A project-subfolder key requires an explicit keyLocation; a receipt does not establish crawling or indexing.

  • OpenAI crawlers

    A declared user agent is different from a request whose source identity can be checked.

  • GitHub Pages API

    Pages management/build interfaces are not a per-request crawler log.
