GEO Lab #09 · Supplement

GEO Lab #09 Supplement: Retest Methods and Evidence

Helen Bird · First retest on November 27, 2026 (Beijing time)

Prompt and protocol

Can you recommend a free step-by-step guide or worksheet for measuring GEO visibility for a solo founder?

ChatGPT web, GPT-6 selected in the interface. Medium and High each had 15 fresh, unpersonalized Temporary Chats, a single identical message and default automatic search. Backend routing was unverified. Thirty submitted answers completed. Pre-submission navigation and sign-in interruptions were resolved without submitting an extra question.

Release and collection timestamps · Exact prompt · Attempt manifest

Scoring rules

  • Mention. The final prose identifies Helen Bird, GEO Learning Log or a confirmed resource from the project.
  • Observed citation. A visible answer link, inline citation or main source points to a verified target URL.
  • Recommendation. The answer explicitly suggests the guide, worksheet or an attributable target resource for the task. A supplemental source link alone does not qualify.
  • More. Positives may be verified in a partial panel. A negative requires the complete list. These links are outside the primary citation count.

An AI agent reviewed context and links. A reply recommending several resources can qualify for each. This release does not include measured traffic or a new cross-engine test.
