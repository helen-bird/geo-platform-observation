GEO Lab Index Monitor

A personal tool for checking the Google index status of GEO Lab's public research pages.

What it does

  • Uses Google's official URL Inspection API to record indexed-version observations for a reviewed list of GEO Lab URLs.
  • Keeps dated snapshots in a private repository and compares changes during scheduled GitHub Actions runs.
  • Uses the official Sitemaps API to check sitemap status. A separately authorized local operation can submit the site's sitemap once.

Who it is for

This is an owner-operated utility maintained by Helen Bird for the GEO Lab learning project. This website does not offer Google sign-in or accept visitors' accounts for monitoring.

Authorization and limits

Routine monitoring requests the webmasters.readonly permission. Sitemap submission requires the separate webmasters permission and is performed locally, with its write credential removed from the local Keychain after a confirmed submission. The scheduled workflow keeps its read-only credential.

Google's permissions can cover other Search Console properties available to the authorizing account. This implementation restricts operations to https://helen-bird.github.io/geo-platform-observation/ and its reviewed URL list.

URL Inspection reports Google's indexed version. It is not a live URL test and does not request ordinary-page indexing. Google indexing changes do not establish improved ChatGPT or Grok discovery or recommendations.

Data handling

Detailed Search Console observations and monitoring history remain private. Public GEO Lab reports and research datasets are separate, reviewed publications. Read the privacy policy for processing, storage and access controls.

Project and contact

View the public project and monitoring code. For general technical questions, use that repository's Issues. Do not post credentials or private Search Console responses in public Issues.
