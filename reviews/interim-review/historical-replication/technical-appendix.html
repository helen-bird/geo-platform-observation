Historical replication and sample-size evidence

Helen Bird · Published 2026-11-10 · v1.0

Methods and collection

Collection took place November 7–10, 2026, Beijing time. OpenAI used gpt-5.6-sol, medium reasoning and a 16-call native web-search cap. The maximum recorded number of web-search calls was 15. Grok used fresh ordinary Expert chats with an explicit web-search chip and both personalization settings disabled for collection. Expert is the visible model label. An exact backend version is unavailable.

The ledger retains 305 submitted attempts and five preparations without a submission. Of the submissions, 300 were selected, four OpenAI outcomes remained unresolved, and one complete Grok response was excluded for mode deviation.

Set overlap is intersection size divided by union size. Unknown sets and comparisons of two observed empty sets are handled separately. Citation domains represent final answer sources. A source panel item is retrieval evidence and is recorded separately.

Across the 150 planned pairs, the median absolute submission gap was 2.35 hours and the maximum was 52.15 hours. Historical interface, tool-cap and source availability differences limit comparisons across batches. The historical ChatGPT consumer interface and the current OpenAI Responses API are separate environments.

Data and reproduction

  • Original prompts and condition identifiers
  • 300 redacted answer records with links, visible queries and source panels
  • 310 attempt histories with recorded submission and failure statuses
  • Normalized outcomes and sets used for calculations
  • All twelve claim decisions · Recomputed summary · Data archive

Reproduce the headline metrics offline with python3 scripts/build_interim_review.py from the repository root. See the GitHub experiment record for the data guide. Cite a commit permalink and an answer ID to point to a fixed record.

Public records omit private conversation links, unverified document-sharing links, credentials, account details, local paths, opaque provider IDs, signed and tracking parameters, and private interface captures. Search evidence unavailable from the provider remains unknown. Exported bodies may differ from the private originals where redaction was necessary.
